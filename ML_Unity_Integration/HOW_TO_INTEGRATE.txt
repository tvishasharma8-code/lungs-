HOW THE ML MODEL IS INTEGRATED INTO UNITY
=========================================

THE IDEA
- Faster R-CNN can't run inside Unity, so the model runs in Python on the laptop.
- Unity sends the patient's CT folder to it and gets back the tumor slices + tumor position.
- Unity then shows the CT slice with a red box AND a red dot on the 3D lung at that spot.

YOU NEED
- tumor_model_v5.pth  (from Google Drive, not in this zip)
- A patient's DICOM folder, e.g. I:\My Drive\Patients\A0265\dicom

STEP 1 - Install Python stuff (once)
  pip install flask torch torchvision pydicom pillow numpy scipy scikit-image

STEP 2 - Put files together
  Put tumor_model_v5.pth in the same folder as the files in 1_python.

STEP 3 - Make the 3D lung of the patient (once, ~3 min)
  python build_patient_mesh.py "I:\My Drive\Patients\A0265\dicom" --out A0265_lungs
  -> makes A0265_lungs.obj and A0265_lungs_meta.json

STEP 4 - Start the model server (keep this window open)
  python tumor_server.py
  -> wait for "server ready"

STEP 5 - Unity
  a) Copy TumorDetector.cs and TumorMarker3D.cs into Assets
  b) Make a folder Assets/Editor and copy Editor/TumorDemoSetup.cs into it
  c) Drag A0265_lungs.obj and A0265_lungs_meta.json into Assets
  d) Drag A0265_lungs from Assets into the Hierarchy
  e) Make a Canvas with: Raw Image, Text - TextMeshPro, 2 Buttons (Prev, Next)
  f) Make an empty GameObject "TumorDetector", add the TumorDetector script,
     drag the Raw Image into "Slice Image" and the Text into "Status Text"
  g) Top menu: Tools > Tumor Demo > Setup Scene
     (connects everything, sets colours and camera automatically)

STEP 6 - Press Play
  - First time: ~10 min (model runs on CPU), then it's saved and instant.
  - You'll see the see-through lung with a red tumor dot + the CT slice with a red box.

NOTE
- The 3D lung and the detection must be the SAME patient.
